## 👋 Bienvenue

Weather Glass est une application météo dans un seul fichier HTML. Elle utilise l'API gratuite Open-Meteo. Vous pouvez rechercher une ville ou utiliser votre position. Aucune inscription n'est nécessaire.

---

## ✨ Ce que vous trouverez

**Météo actuelle.**  
Affiche la température, la condition, l'humidité, le vent, le lever et le coucher du soleil, et la probabilité de pluie.

**Prévisions sur 7 jours.**  
Une rangée montre les températures maximales et minimales pour les sept prochains jours.

**Recherche de ville.**  
Entrez un nom de ville pour obtenir sa météo.

**Géolocalisation.**  
Un bouton utilise votre position pour afficher la météo locale.

**Design glassmorphism.**  
Une carte transparente avec un fond dégradé animé.

---

## 🧭 Comment ça marche

**1. Ouvrez le fichier HTML dans un navigateur.**  
Aucune installation n'est requise.

**2. Autorisez la géolocalisation ou recherchez une ville.**  
L'application utilise votre position ou le nom saisi.

**3. L'application récupère les données depuis Open-Meteo.**  
Les données sont gratuites et sans clé API.

**4. Les conditions actuelles et les prévisions s'affichent.**  
La carte montre la météo du moment et les 7 prochains jours.

C'est tout. Aucune configuration.

---

## 🛠️ Petits coups de main

**Faut-il une clé API ?**  
Non. Open-Meteo est gratuit et ne demande pas de clé.

**Puis-je l'utiliser hors ligne ?**  
Non. Une connexion Internet est nécessaire pour charger les données météo.

**Quelles unités sont utilisées ?**  
Températures en degrés Celsius, vent en km/h.

**La géolocalisation est-elle obligatoire ?**  
Non. Vous pouvez rechercher une ville manuellement.

## 👋 Welcome

Weather Glass is a weather app in a single HTML file. It uses the free Open-Meteo API. You can search for a city or use your location. No sign-up is required.

---

## ✨ What you'll find

**Current weather.**  
Shows temperature, condition, humidity, wind, sunrise and sunset, and rain chance.

**7-day forecast.**  
A row shows the high and low temperatures for the next seven days.

**City search.**  
Enter a city name to get its weather.

**Geolocation.**  
A button uses your location to show local weather.

**Glassmorphism design.**  
A transparent card with an animated gradient background.

---

## 🧭 How it works

**1. Open the HTML file in a browser.**  
No installation is required.

**2. Allow geolocation or search for a city.**  
The app uses your position or the name you enter.

**3. The app fetches data from Open-Meteo.**  
The data is free and needs no API key.

**4. Current conditions and forecast appear.**  
The card shows the current weather and the next 7 days.

That's it. No configuration.

---

## 🛠️ A little help

**Do I need an API key?**  
No. Open-Meteo is free and requires no key.

**Can I use it offline?**  
No. An internet connection is needed to load weather data.

**What units are used?**  
Temperatures in Celsius, wind in km/h.

**Is geolocation required?**  
No. You can search for a city manually.
